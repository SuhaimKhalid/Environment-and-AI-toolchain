# Environment-and-AI-toolchain

Week 1 capstone for documenting the local development environment and AI-assisted workflow.

## Node Version

```bash
node -v
# v24.14.0
```

## Getting Started

1. Clone this repository.
2. Verify Node.js **v24.14.0** is installed (`node -v`).
3. Run the entry point:

```bash
node src/index.js
```

Expected output:

```
AI Development Capstone
```
