# Project Development Guidelines

## Stack

- Node.js
- JavaScript
- Git
- GitHub

## Coding Conventions

- Use clear and descriptive names for variables and functions.
- Keep functions small and focused.
- Follow consistent formatting.
- Review AI-generated code before committing it.
- Never commit passwords, API keys, or other secrets.

## Git Conventions

Use Conventional Commits for all commit messages.

Examples:
- feat: add new feature
- fix: correct a bug
- docs: update documentation
- chore: update project configuration

## AI-Assisted Development

Cursor may be used to assist with development, documentation, debugging, and code review. AI-generated changes must be reviewed and understood before they are committed.
